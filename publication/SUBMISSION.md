# Kane CLI Online Hackathon submission draft

## About the project

FixProof compares a browser bug reproduction across a baseline and a candidate. The developer supplies both application URLs, a written expectation, and a few nearby controls. The workflow runs Kane CLI on each build and records the browser observations, build fingerprints, and evidence status. It reports a correction, a persistent failure, a regression, a pass on both builds, or an incomplete comparison.

The synthetic cart has a deliberately introduced defect. Kane reproduced the quantity and total reverting on reload. Codex used the failing evidence and Meta’s focused patch proposal to change when the candidate persists quantity. The same Kane check then verified that quantity and total survived reload, with the live-total control passing on both builds.
